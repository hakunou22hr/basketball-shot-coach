# Basketball Shot Coach

シュート練習の結果とフォームを、その場で記録・振り返りできる日本語対応の Web アプリです。

## 主な機能

- 成功数・試投数・コート位置・フォーム感覚を練習セットごとに記録
- 成功率、総シュート数、連続記録日数を自動集計
- 直近 5 セットの成功率をミニチャートで可視化
- 記録内容に応じたコーチングヒントを表示
- ブラウザの `localStorage` に記録を保存

## 起動方法

ビルドは不要です。リポジトリのルートで静的ファイルサーバーを起動してください。

```bash
python3 -m http.server 4173
```

その後、ブラウザで <http://localhost:4173> を開きます。

## テスト

```bash
node --test
```
